## How it works

1. **Run Scorecard.** Add the GitHub Action to a repository you own, run the
   command-line tool on any repository, or look up results from the weekly
   scan.
2. **Scorecard runs its checks.** Each check looks at one practice, such as
   code review, pinned dependencies, or branch protection, and scores it
   from 0 to 10.
3. **Read the results.** Scores are weighted by risk into an aggregate score.
   Use the individual checks to decide what to improve or which risks to
   accept.
