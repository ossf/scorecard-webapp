## Report a problem

- **Scorecard itself:** [open an issue](https://github.com/ossf/scorecard/issues)
  after searching existing ones.
- **This website:** use "Report a problem with this page" at the bottom of
  any page.
- **A security issue:** follow the
  [security policy](https://github.com/ossf/scorecard/blob/main/SECURITY.md).

## Contribute

- Fix a typo or improve a page here with "Edit this page". You don't need to
  install anything.
- Contribute code by following the
  [contributing guide](https://github.com/ossf/scorecard/blob/main/CONTRIBUTING.md).
